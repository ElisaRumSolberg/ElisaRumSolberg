### 🛡️ SafeHer
**Privacy-first women's health and personal safety platform**

SafeHer is a software project that combines women's health and personal safety in one platform.

The product is built around three main areas:

- **Women's Health** – cycle tracking, symptoms, mood, pain, sleep, energy, stress, and daily health check-ins
- **Everyday Safety** – trusted contacts, safety check-ins, timers, journey sharing, and location-sharing concepts
- **High-Risk Safety** – discreet access mechanisms, Safety PIN, SOS flows, and privacy-focused safety features

The project has given me hands-on experience with building a larger system where privacy, reliability, and user safety directly influence technical decisions.

Some of the engineering challenges include:

- user-scoped sensitive data
- secure local storage
- authentication and access control
- SOS state management
- duplicate-event prevention
- timer and concurrency handling
- trusted contact flows
- location-sharing architecture
- privacy-by-design principles

**Current status:**  
Working prototype • Health MVP • Safety foundation • Ongoing technical hardening

**Focus:**  
Software Engineering • Backend Systems • Privacy • Security • Product Development

### ⚖️ [ClearRights](https://github.com/ElisaRumSolberg/clearrights)
**Explains Norwegian official letters in plain language**

Built for LexHack 2026. Upload a letter from a landlord, NAV or a debt collector, and ClearRights explains it in your language, calculates the deadlines and points to the right agency and law. The model only classifies the letter; agencies, laws and links come from a knowledge base checked against Lovdata.

**Technologies:**  
Next.js • TypeScript • Gemini • Google Cloud Run
